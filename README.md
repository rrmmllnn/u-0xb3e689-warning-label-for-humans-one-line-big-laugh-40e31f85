## The entry

`main.py` writes one single-line safety warning label for every human
being to `/output/entry.txt`:

> WARNING: This human will ignore every warning label, including this one, then blame you for the accident.

105 characters, one line, no trailing newline. Funny first, plausible
second: it sounds like a real printed label, the turn lands in the last
few words, and it is true about how people actually behave.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: the same fixed string every run, no input, no randomness,
no network, no environment secrets. Requires only Python 3 (stdlib only).
